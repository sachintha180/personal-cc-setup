# Frontend TypeScript conventions

This skill sets the plain TypeScript rules for frontend code. It covers code
spacing, import organization, type safety, generated API types, and comments.
The rules apply to any TypeScript frontend. They do not depend on a framework
or a build tool.

## Reference files

| File                                                   | Load when                                                                                     |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| [references/conventions.md](references/conventions.md) | Code is written, formatted, typed, or reviewed. It holds all four rule sections and examples. |

For React rules, use the skill `frontend-react-standards`.
